## Featured projects

**[Olist Weather-Delay Analysis](https://github.com/Sunny53/Automated_Logistics_Risk)**: a dbt + Snowflake pipeline joining 99,441 Brazilian e-commerce orders with 10M+ historical weather records. Orders were 3.2x more likely to be late when severe weather hit the delivery destination (17.3% vs. 5.3%). Includes a Type 2 slowly changing dimension, automated data quality tests, and a [walkthrough video](https://www.youtube.com/watch?v=No_hNBfRKsI).

**[NFL Stats Pipeline](https://github.com/Sunny53/nfl-stats-pipeline)** ([live dashboard](https://nfl-stats-pipeline.streamlit.app/)): an ETL pipeline and Streamlit app covering 2015-2025 QB and WR performance. Star-schema PostgreSQL database, 12 SQL leaderboard views, custom efficiency and consistency metrics, unit tests, and CI.
